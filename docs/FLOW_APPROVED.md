# AutoKey — Flow ที่ยืนยันแล้ว

เอกสารนี้บันทึกเฉพาะสิ่งที่ **ตกลง / ยืนยันแล้ว** จากการคุยกับ user  
รายการที่ยังไม่ยืนยันจะ **ไม่** อยู่ในไฟล์นี้

---

## ขอบเขตการรัน

| หัวข้อ | ที่ยืนยัน |
|--------|-----------|
| แพลตฟอร์ม | Windows + Express Accounting |
| จอ | 1920×1080, scale 100% |
| เริ่ม Auto | หลัง user เปิด Express และ login แล้ว — user เตรียมหน้าจอเองก่อนกด **เริ่ม** |
| 1 ครั้งรัน | **1 ฐานข้อมูล / 1 บริษัท Express** (user เลือก DB เองก่อนรัน — AutoKey ไม่สลับบริษัทให้) |
| 1 แถว Excel | **1 ใบ PV = 1 vendor** (ค้นหาชื่อใหม่ทุกแถว) |
| Excel | อ่านทุกชีตที่รองรับในไฟล์ — ทำ **ทุกแถว** ในแต่ละชีต |
| หัวข้องาน | สมุดรายวันจ่าย (PV) — ค่าทำบัญชี |

## ข้อมูลจาก Excel / UI

| ข้อมูล | แหล่ง | หมายเหตุ |
|--------|-------|----------|
| ชื่อ vendor ใน PV | คอลัมน์ **นิติบุคคล** (ชื่อเต็ม) | ใช้กับ F8 ค้นหาใน dialog |
| ยอดค่าบริการ | Excel ตามชีต | → บัญชี `5330-05` เดบิต |
| ยอดภาษีซื้อ | Excel ตามชีต | → บัญชี `1154-00` เดบิต (เฉพาะแถวที่มี VAT) |
| ยอดเครดิต / WT | Excel ตามชีต | → บัญชี `1111-00` เครดิต (หัก WT ถ้ามี) |
| เลขที่ใบกำกับ | คอลัมน์ใน Excel (ถ้ามีในชีต) | ใส่ใน dialog ใบกำกับภาษีซื้อ |

| รายละเอียด PV | ช่อง UI — **ข้อความเดียวกันทุกแถว** ในรอบนั้น | user พิมพ์ก่อนรัน |

## Flow 2 — สมุดรายวันจ่าย (ทำซ้ำทุกแถว Excel)

ลำดับที่ **ยืนยันแล้ว** ต่อ 1 แถว:

### 0) ก่อนเริ่มแถวแรก (ครั้งเดียวต่อรัน)

1. AutoKey โฟกัสหน้าต่าง Express (Windows)
2. กดเมนู **`5` → `1` → `2`** เปิด **สมุดรายวันจ่าย (PV)**

### 1) สร้างใบ PV

3. กด **`F2`** สร้างรายการใหม่
4. กรอก **วันที่ PV** (จาก UI)
5. **`Tab`** ไปช่องรายละเอียด → พิมพ์ **รายละเอียด** (จาก UI)

### 2) แถวบัญชี — ค่าบริการ

6. กรอกรหัส **`5330-05`**
7. **`Tab` × 2** แล้วกด **`F8`** → เปิด dialog เลือก vendor
8. กดปุ่ม **ค้นหา** (จับภาพ `btn_search.png` หรือ fallback **`Tab` × 2 → `Enter`**)
9. พิมพ์ชื่อ **นิติบุคคล** → **`Enter`** เลือก vendor
10. กรอก **ยอดเดบิต** (ค่าบริการ) → **`Enter`** ยืนยันแถว

### 3) แถวบัญชี — ภาษีซื้อ (เฉพาะแถวที่มี VAT)

11. กรอกรหัส **`1154-00`**
12. **`F8`** ค้นหา vendor (ชื่อเดิม) → กรอกยอด VAT → **`Enter`**
13. Dialog **ป้อนเลขที่ใบกำกับภาษีซื้อ**
    - พิมพ์ **เลขที่ใบกำกับ** (จาก Excel ถ้ามี) → **`Enter`**
    - พิมพ์ **เลขผู้เสียภาษี** (ถ้ามี) → **`Enter`**
14. Dialog **ภาษีหัก ณ ที่จ่าย** ที่เด้งอัตโนมัติ → กด **`Esc`** ปิด (ไม่กรอกฟอร์ม WT)

### 4) แถวบัญชี — เงินสด

15. กรอกรหัส **`1111-00`**
16. **`F8`** ค้นหา vendor → กรอก **ยอดเครดิต** (ยอดรวม − WT ถ้ามี) → **`Enter`**

### 5) บันทึก

17. กด **`F10`** บันทึก
18. ถ้ามี VAT — dialog **ป้อนรายละเอียดรายการภาษีซื้อ** หลัง F10  
    - Express กรอกยอด/ชื่อให้แล้ว  
    - AutoKey กรอกเฉพาะ **เลขผู้เสียภาษี** แล้ว **`Enter`**  
    - **ไม่** พิมพ์เลขที่ใบกำกับใน dialog นี้

### 6) วนซ้ำ

19. กลับไปขั้น **F2** สำหรับแถว Excel ถัดไป จนครบทุกแถว

| วิธี | รายละเอียด |
|------|------------|
| หลัก | OpenCV จับภาพ `btn_search.png` แล้วคลิกกลางปุ่ม |

| ใช้กับ | **F8 ค้นหา vendor** ใน PV เท่านั้น |

## สิ่งที่ยืนยันว่า **ทำมือ** (ไม่ Auto)

- **โฟล์แรก — เลือกบริษัท/DB** ก่อนเริ่มงาน (ไม่ดึงชื่อบริษัทจาก Excel อัตโนมัติ)
- **โฟล์สุดท้าย — เปลี่ยนบริษัท `8` → `8`** หลังจบงาน (ทำมือเมื่อต้องการเปลี่ยน DB)

---

## การหยุดฉุกเฉิน

- กด **`Ctrl+F9`** หรือ **`Esc`** เพื่อยกเลิกขณะรัน
